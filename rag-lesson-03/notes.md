# Lesson 3 — Understanding Embeddings

## 1. What problem do embeddings solve?

Imagine your document contains:

> Python is a programming language used for automation and AI.

A user asks:

> Which language can I use to automate tasks?

The words in the question are different from the words in the document, but the meanings are related.

A normal keyword search might struggle to match them. Embeddings help represent the meaning of text numerically, making it possible to search for semantically similar text.

## 2. What is an embedding?

An embedding is a list of numbers generated by an embedding model to represent text.

For example, a simplified illustration might look like this:

Text

“Python is useful for automation.”

Embedding model

Vector representation

[0.21, -0.48, 0.73, 0.16, ...]

These numbers are only illustrative, not actual embeddings for that sentence.

The embedding model determines the vector's dimensions and values. Text with related meanings can have vectors that are close together according to a similarity measure.

Important: An embedding is not a summary or a translation. It is a numerical representation designed to capture useful features of the text.

## 3. How embeddings work in a RAG pipeline

When a user asks a question, the system also converts the question into a vector. It then compares that query vector with the stored document vectors to find relevant chunks.

### Step 3: Understand the output

Your output will contain results similar to these:


The decimal values will depend on the model output. The key points are:

- `embed_documents(chunks)` generates one vector for each chunk.
- `len(vector)` reports the number of dimensions. This model produces 384-dimensional vectors.
- `vector[:5]` displays only the first five numbers so that you don't have to print the entire vector.
- Each vector represents its corresponding chunk.

## 5. What about similarity?

Generating embeddings is only half the story. RAG needs to identify which chunks are most relevant to a question.

For example:

| User question                         | Potentially relevant chunk                         |
| ------------------------------------- | -------------------------------------------------- |
| Which language helps with automation? | Python is used for automation and AI.              |
| How does RAG use documents?           | RAG retrieves relevant information from documents. |
| What are text embeddings?             | Embeddings represent text as numerical vectors.    |

A similarity measure, commonly cosine similarity, compares the vectors. The system can rank the chunks by similarity and retrieve the most relevant ones.
